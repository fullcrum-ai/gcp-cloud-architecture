## 📝 How I Document Each Challenge

For every completed challenge I capture:

1. **What it covered** — services and concepts introduced
2. **Architecture pattern** — the real-world design pattern behind the lab
3. **ANZ client relevance** — how this applies to AU/NZ enterprise or mid-market clients
4. **Azure equivalent** — mapping to Azure for multi-cloud context
5. **Cost considerations** — rough cost awareness for each service pattern
6. **Code or config** — any reusable Terraform or scripts saved to the relevant folder
